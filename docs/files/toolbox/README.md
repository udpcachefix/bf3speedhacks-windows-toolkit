# Toolbox

This directory contains the 30 files imported from the supplied `Amin.7z`, `Cleanup.7z`, `Network reset.7z`, and `nvidia.7z` archives.

Files are grouped by function without changing their bytes. `MANIFEST.md` and `SHA256SUMS.txt` record their source archive, original path, size, and SHA-256 digest.

Read `../docs/TOOLBOX_REFERENCE.md` before executing or importing any file. Several items make machine-wide changes to networking, Windows Update, power policy, permissions, graphics-driver state, or other system configuration.
