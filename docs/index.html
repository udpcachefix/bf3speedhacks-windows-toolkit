udp legacy Windows Toolkit

A consolidated Windows tooling repository and GitHub Pages documentation site. Maintained scripts, BIOS references, legacy WFiles, network utilities, cleanup tooling and NVIDIA profiles are kept in one auditable structure.

Read before running. Several files change machine-wide networking, power, Windows Update, permissions or NVIDIA Base Profile state. Each imported file has a documented behavior and risk rating.
