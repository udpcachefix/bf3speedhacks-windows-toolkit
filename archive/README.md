# Historical archive

This directory contains preserved legacy material from the two predecessor repositories.

* `legacy-workarounds/` contains older examples retained by the Windows Workarounds / BIOS project.
* `wfiles-original/` contains the original WFiles collection preserved for traceability.

These files are not part of the maintained execution surface. Several perform destructive, obsolete, security-reducing, or hardware-specific changes.
